Common questions

How small should the first version be?

Smaller than feels comfortable. The useful test is whether one real customer would pay for it as it stands, doing the single job they currently struggle with. Everything else waits. MVP development keeps the first build cheap enough that being wrong about a feature costs weeks instead of a year, which happens to most products.

What is multi-tenancy and why does it matter?

Multi-tenancy means one application serves many customer organisations, each seeing only their own data. It matters because retrofitting it is painful and risky. Separating tenants from the start affects the database design, every query, permissions and backups, so it is far cheaper to decide before launch than after your fourth customer signs up.

Where will our customers' data be hosted?

In Australian data centres by default, usually Sydney, which keeps latency low for local users and makes data sovereignty an easy question to answer when larger buyers run their procurement checks. If you expect overseas customers, we discuss regions early, along with the Privacy Act 1988 obligations that follow personal information offshore.
